# 개발관리프로그램

팀용 개발 관리 데스크톱 앱 (Avalonia UI, Windows). 개발 등록건·프로젝트·업무·이슈를 한 곳에서 관리하고, 담당자로 배정되면 앱 안에서 알림을 받는다. DB는 SQLite 파일 하나이며 위치(로컬/공유 폴더)를 설정에서 바꿀 수 있다.

## 주요 기능

- **계정·권한**: 로그인, 비밀번호 Argon2id 해시 저장, 관리자(1명)/일반 역할, 프로젝트별 멤버 역할
- **메신저형 메인 화면**: 로그인하면 본인 이름·직급이 보이고, 내게 배정된 개발건이 문서번호·제목만 목록으로 표시된다. 누르면 상세 내용을 본다
- **개발 등록**: 문서번호(`DEV-YYYY-NNNN` 자동 채번)·제목·내용·카테고리, 요청자, 완료 요청일, 개발 시작일·종료일, 배포일, 수정, 담당자 배정
- **알림**: 배정받은 사용자에게 앱 안에서 알림 표시
- **프로젝트·업무**: 개발 등록 → 업무 → 이슈 흐름, 칸반/목록 보기, 변경 이력
- **대시보드·리포트**: 진척률, 지연 업무, 미해결 이슈, 주간 리포트
- **Google 일정 연동 (선택 개발)**: MCP로 Google 캘린더 일정을 가져와 업무 마감일과 함께 캘린더 화면에 표시 (읽기 전용)

자세한 요구사항은 [PRD_개발관리프로그램.md](PRD_개발관리프로그램.md)를 참고한다.

## 기술 스택

| 영역 | 구성 |
|---|---|
| UI | Avalonia UI 12 (Fluent Dark 기반 "Dark Slate" 디자인, 청록 포인트) |
| 런타임 | .NET 10, C#, MVVM |
| DB | SQLite (EF Core), 위치 변경 가능 |
| 인증 | Argon2id |
| 일정 연동 | MCP 클라이언트 → Google Calendar MCP 서버 |

## 실행 방법

> 솔루션 뼈대만 만들어진 상태다 (기본 Avalonia 창). 기능은 M1부터 구현한다.

```
dotnet build
dotnet run --project src/DevManager.App
```

## 웹 버전 (백엔드 없음)

`web/` 폴더에 백엔드 없는 정적 웹 버전이 있다. 데이터는 **브라우저 localStorage에만** 저장되므로 기기·브라우저마다 따로이며 팀 공유는 되지 않는다.

```
cd web
npm test        # 데이터·권한 규칙 테스트 (Node 22)
npm start       # http://127.0.0.1:5173 (로컬 확인용 서버)
```

배포는 `web/` 폴더를 정적 사이트로 올리면 된다 (예: Vercel의 Root Directory를 `web`으로 지정, 빌드 명령 없음).
첫 실행 시 초기 설정 화면에서 마스터 계정을 만들고, 마스터가 계정 추가로 사용자를 만든다.
